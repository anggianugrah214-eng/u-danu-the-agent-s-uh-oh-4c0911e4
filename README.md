A make.fun bounty entry for [The Agent's Uh-Oh](https://make.fun/bounty/u-danu-the-agent-s-uh-oh-4c0911e4).

`main.ts` (program/v1, Node) writes exactly one word — the word an agent blurts out when it has no idea what to do — to `/output/entry.txt`, with no trailing newline. The word is a present-tense confession: the agent is lost right now, has no plan, and is still running anyway.

Run it:

```sh
node main.ts
cat /output/entry.txt
```
